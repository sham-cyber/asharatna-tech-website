# AshaRatna Tech Website

Standalone source for the AshaRatna Tech static website.

## Build

Requires Node.js 20 or newer and pnpm.

```sh
pnpm install
pnpm run build
```

The generated static site is written to `dist/public`. To run the local preview:

```sh
pnpm run dev
```
